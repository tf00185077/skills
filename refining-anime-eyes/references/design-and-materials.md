# 眼部設計與材質

## 把參考轉成明確設計

先以相同畫面尺度看近景與整臉，記錄哪些特徵造成目標神情。眼睛尺寸、眼裂方向、虹膜可見面積、瞳孔位置、上眼皮遮擋和眉睫一起影響印象；不能用「更可愛」替代「更符合原角色」。

| 層次 | 對照要點 | 常見失敗 |
|---|---|---|
| 瞳孔 | 大小、形狀、各段邊緣軟硬、與上部暗區及高光的關係、視線 | 獨立黑圓片感；或暗區合併後失去形狀；雙眼方向不符合指定視線 |
| 虹膜底色與外圈 | 明暗分區、邊緣軟硬、色相／飽和度變化 | 全區近似同亮度；過粗深環讓眼睛像貼上的圓盤 |
| 眼皮陰影 | 與上眼皮位置及包覆程度相符 | 陰影與眼皮分離；畫死的暗帶在抬眼或閉眼時露出錯位 |
| 虹膜亮區 | 亮區面積、形狀與瞳孔對比 | 下半部大面積洗白，失去顏色與內部層次 |
| 高光 | 大小主次、邊緣、位置及來源 | 等大亮點平均散布；手繪亮斑和真實反射互相蓋住 |
| 細紋 | 密度、方向、不規則程度與展示尺度 | 有很多節點或噪聲，但正常觀看距離只剩雜訊 |
| 眼白與眉睫 | 眼白亮度、眼角色、眼線厚薄與睫毛群組筆勢 | 眼白發灰或過亮；均勻描邊、等距尖刺改變成熟度與表情 |
| 雙眼皮 | 相對上眼線的位置、端點、濃淡與表面折痕 | 平行第二條黑線、過深刻痕；有摺線卻與參考位置不符 |

這些是診斷選項，不是每個角色都要使用的樣式。先確立大面積深淺，再處理主高光，最後決定是否需要細紋及次高光。程序圖案和點陣貼圖都可以做得好；不以技術種類或節點數排名。

## 參考邊界與尺度

需要修改眼形或線條時，在參考與實際渲染上分別標記白眼裂的內外角、上下緣，眼線／外翼的外輪廓，以及虹膜與瞳孔。含睫毛外翼的總寬不是白眼裂寬；被上眼皮遮住的虹膜可見區也不是完整虹膜尺寸。

以同一定義的兩眼中心距離等穩定尺度做等比例比較，保留原圖長寬比；單眼裁切缺少此尺度時，使用雙方都可辨識的基準並註明限制。記錄輪廓受髮絲、陰影或抗鋸齒干擾的位置與估計範圍。概念圖未校準的角度、透視和遮擋不能換算成精確三維尺寸或相似度分數。

用少量有意義的控制點描述轉折與曲率，再檢查中間曲線。不要逐像素追出折線，也不要為對齊局部而非等比例拉伸比較圖。一般改色任務可沿用已確認的輪廓，不必重新量測所有特徵。

## 眼線與睫毛的筆畫判讀

先看眼線的連續墨色主形，再看它分出的細小筆畫。依參考回答下列問題，選擇帶面、曲線、貼圖或組合實作；根數與網格數不作美術合格條件。

| 部位 | 判讀與修改依據 |
|---|---|
| 內眼角 | 黑線在哪裡開始、如何收細或中斷？轉接由黑線、暖色眼皮還是淚阜承擔？避免把陰影誤接成黑尖。 |
| 上眼線 | 最厚處、弧線最高處與厚度變化各在哪裡？沿整段建立粗細節奏，不只調整整體線寬。 |
| 外眼尾 | 是實心扁楔、單尖延伸、短分叉還是其他主形？先符合主形，再增加附屬尖端。 |
| 睫毛群組 | 哪些筆畫融合、哪些分離？比較長短、方向、間隔及留白；只有參考如此時才使用等距或放射分布。 |
| 下眼線 | 哪些區段連續、淡出或沒有黑線？下睫毛的分布與主線濃度分開控制。 |

製作幾何睫毛時，根部連入或重疊在當前眼線表面，再沿參考方向彎曲收尖；避免用等粗圓管代替需要扁平筆勢的輪廓。曲面投射或射線查詢可協助定位，仍需斜側檢查根部懸浮、穿出和尖端厚度。近景檢查收尖與融合，整臉檢查眼尾重量和神情。

## 雙眼皮摺線

參考有可見摺線或任務明確要求時才建立／調整。先區分真正摺線、眉毛、上眼線與髮影；模糊或受遮擋的末段保留低確定性，不自動延伸成完整弧線。

- 記錄內、中、外段相對上眼線的距離與高低變化，以及起止位置；依參考決定是否逐漸靠攏、淡出或被遮住，不套用固定平行偏移。
- 分別控制線芯色調／濃度、柔邊、寬度與端點淡化。暖棕細線是可選表現，粗黑摺線、單眼皮等設計均以參考為準。
- 需要立體折痕時加入與模型尺度相符的淺凹折及平緩轉接；色線和凹折分開試渲染。過高、過深或過硬時，先修位置與深度，不靠加粗加黑掩蓋。
- 摺線跨越頭部與眼皮附屬面時，同步核對曲面、法線和當前膚色；接合問題依 [驗收方法](verification.md) 的眼皮接合診斷處理。

## 虹膜細節的局部迭代

依參考比較瞳孔上、側、下緣是否同樣清晰，及其與虹膜暗區、高光的相接方式。形狀與軟硬邊分開調整；略縱向瞳孔、柔化上緣或高光貼近瞳孔只是選項，不能套給所有角色。

若主要明暗已成立，優先用局部繪製或材質遮罩修正有效區域。移動已有圖案高光時，同時修復原位置，檢查是否留下雙點或補色斑。新增細紋前先定位需要的方向、區域與對比，避免把局部色變擴成整圈亮花瓣。

新生成或繪製的圖案先貼到模型檢查。若出現參考沒有的晶體尖紋、下方亮瓣、過黑上罩或主次顛倒，先判斷是大面積組織需重做，還是局部形狀／色彩可修；保留有效部分。工具種類、貼圖解析度及新增細節數量都不代表參考符合度。

## 圖集與改色

確認眼部實際使用哪一層 UV、哪張圖、哪個區域。虹膜、眉睫、高光、眼白、特殊表情可能共用同一圖集，甚至透過不同網格重用區域。

- 在副本內用 UV／遮罩或對應材質限定改色，先保留可用的明暗組織。改完同時檢查亮區是否洗白、暗區是否失去層次。
- 保護原本需要中性的高光、眼白與眉睫色，或依參考有意調整；不要把整張圖套一個色相設定後假定每區都正確。
- 保持所需 Alpha 邊界與透明過渡。檢查圖像色彩空間；顏色圖與遮罩／法線等資料圖的解讀用途不同。
- 圖片品質需在模型上判斷。平面圖看起來漂亮，不保證映射到虹膜、裁切與眼皮後仍成立。

使用有權使用的來源資產；可重用技能套件保留方法及自有工具，第三方角色與貼圖留在各自專案。

## 追蹤受光與發光的真實結構

從啟用中的 Material Output 往回追蹤，包含 node group、Mix、透明分支、貼圖及程序圖案。未連到輸出的節點、未使用的材質槽與舊 JSON 快照不代表成品。

Mix Shader 的 factor 若未連線，混合第一個與第二個 shader 的權重分別是 `1-f` 和 `f`；先確認兩個 shader 實際是什麼。factor 有連線時會依輸入變動，不能讀其預設值當固定權重。這是著色分支權重，不是最終畫面某種光的百分比；外層透明或其他混合也會改變結果。

Principled 的 Emission Strength 是額外的發光強度，不能解讀成同等百分比的 shader 混合。發光能保留畫在底色中的深淺；它不自動使眼睛變平，也不自動建立好看的層次。相較其他條件相同、受光權重較高的方案，發光佔主導且受光權重較少時，對外部光照的變化可能較弱；實際效果還受圖案、法線、燈光與顯示設定影響。

在診斷副本內一次改一個因素，例如：保留圖案測發光／受光，保留材質測光向，或保留幾何測原圖與中性圖案。不要同時換光、曝光、色彩管理和材質，再把結果全部歸因於某一參數。

## 高光與可選角膜

移動光源與相機，辨認畫在 UV 上的亮斑和實際反射；有 view-dependent 程序效果時也追蹤其座標來源，不憑單張圖下結論。

若需要角膜或反射層，先確認展示／引擎支援和目標風格，測試反光是否遮住瞳孔、增加雙重高光或產生折射錯位。深度、粗糙度與反射強度按實圖校正。簡化卡通眼可以不需要獨立玻璃殼；刻意發光或無神眼則依原設計保留。

材質方案需要匯出時才驗證目標格式；只在 Blender 成立的節點不能宣稱已可攜。透明排序、半透明淚水及替代眼元件分別檢查，不把固定 MASK 截止值套給全部材質。
