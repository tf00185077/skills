# 日系 3D 眼睛精修

依參考建立眼形、明暗、高光與眼皮遮擋的配合，讓眼睛呈現指定的神情。以最終畫面的層次與角色一致性驗收，不把改色、加亮點、增加節點或改成物理材質當作完成。

## 鎖定目標與實際來源

使用目前核准的參考及眼睛比例。沒有新參考時保留原有眼形、虹膜大小、視線和情緒，只修已辨認的問題；刻意無神、低對比或發光的眼睛也可能是正確目標。單純改色任務只調相關色彩，不擴大成換眼形或改整張臉。

保留原檔並另建候選。查看實際保存模型的可見眼部物件、材質槽、UV 圖集、貼圖、材質輸出、表情與控制模式。舊腳本、節點名稱或未使用的材質不能代替目前輸出的證據。

需要核對連線時使用 [唯讀材質稽核](scripts/audit_eye_materials.py)，先查看其 `--help`。選定實際眼部物件或材質後記錄輸入方向、數值和圖片；報告只提供結構證據，不判定藝術品質。

## 把「有神」拆成可修改的項目

固定相機、尺度、姿勢、燈光及色彩管理，同時查看眼部近景與整張臉。依參考列出：

- **眼形與神情：** 白眼裂、眼線外輪廓、虹膜與瞳孔各自的大小與位置，雙眼視線、上眼皮遮擋、眼角和眉睫。
- **明暗配置：** 瞳孔、虹膜、外圈、眼白與上眼皮陰影是否分得開；暗部是否糊成一片、亮部是否洗白。
- **高光來源：** 哪些亮斑畫在貼圖／程序圖案內，哪些來自真實反射；兩者的形狀、面積和位置是否互相干擾。

上暗下亮、深外圈、放射紋與大小高光是可用的設計手段，按參考選擇，不強迫每種眼睛全部具備。先讀 [眼部設計與材質](references/design-and-materials.md) 中與本案相關的段落；眼角、睫毛或雙眼皮不符時，使用其中的邊界定義、筆畫判讀與摺線方法。把本輪差異連成「參考特徵 → 模型偏差 → 修改項 → 圖上驗收位置」，保留遮擋區的不確定性。

| 現象 | 優先核對 |
|---|---|
| 有紫色與白點，仍像圓片 | 圖案的明暗面積、虹膜／瞳孔關係、眼皮遮擋及受光能力 |
| 換光向仍幾乎不變 | 最終輸出中的 Emission、toon 或固定圖案；依風格判斷是否需要調整 |
| 亮點很多但瞳孔讀不清 | 貼圖亮區與實際反射是否疊加洗白 |
| 改虹膜色卻影響眉睫或眼白 | 共用圖集、材質／UV 範圍及 Alpha |
| 正面成立，斜側或閉眼穿出 | 眼皮與眼球深度、視線控制、形狀鍵及替代表情元件 |

## 逐項修改

需要改眼形時先校正輪廓與遮擋；在本輪範圍內確立主要明暗，再補細紋及小高光。已有成熟貼圖時保留其中有效的明暗組織；新建圖案時依照參考安排形狀與面積，不只增加噪聲或亮點。圖集內分區改色，保護其他區域與透明輪廓。

依風格保留合適的 Emission 或受光分支。檢查 Mix Shader 的實際連線；Mix 的權重與 Principled 的 Emission Strength 不是同一種量。案例的比例、配色、睫毛根數與光點位置留在專案紀錄，不當通用配方，也不以「全關發光、加玻璃角膜」作預設修法。

眼形需要改動時分別處理眼裂、虹膜與瞳孔；同步核對眼皮、眉睫和相關控制，避免整組縮放造成另一種神情。需要的幾何與功能驗證見 [驗收方法](references/verification.md)。任務只要求診斷時，保留原檔並交付證據；要求精修時，完成候選模型與實際驗收。

## 保存後驗收

重新開啟候選檔，輸出相同條件的眼部近景與整臉對照，並檢查斜側、必要的視線／閉眼及中間狀態。換一個診斷光向，分清固定圖案和受光反應；最後回到原展示設定驗收。

分開回報結構／功能結果與參考符合度，列出「看見的缺陷、已確認原因、修改項、剩餘差異」，連同修改檔及實際圖交付。無穿模、圖片已封裝或元件齊全不能代表筆觸與神情已還原；貼圖高光不能冒稱角膜反射，鍵數量或 UV 數值未變不能代替功能與貼圖外觀驗證。
