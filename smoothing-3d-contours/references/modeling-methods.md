# 建模方法：按曲折的來源選工具

## 曲線連續性

- 位置接上，只說明沒有裂縫；還可能有轉角。
- 切線方向接上（G1），可消除接點的明顯折角；兩側彎曲程度仍可能突然改變。
- 彎曲程度也銜接（G2），對連續光滑區的高光流動有幫助；不應強加於髮尖、眼口邊界或有意的折線。

對多邊形模型，通常驗收可見的近似曲面及預期展示尺度，而非宣稱整個離散網格取得精確 G2。控制點、切線、曲率與著色法線是不同層次。

## 新建曲線與程序化髮束

1. 用主弧線描述走向。控制點放在必要轉向與形狀變化處；少量點先形成正確大輪廓，再補足局部控制。
2. Bézier 的非零控制柄共線且分處接點兩側，可讓進入與離開的切線同向；柄長仍影響彎曲。自動柄是起點，檢查是否過衝、形成不必要 S 彎，別把提高解析度當成修正控制點。
3. 沿弧長合理分布取樣。用插值連接手動位置表時，檢查段與段的斜率及彎曲變化，避免只連續位置的分段線性伸縮。局部變形也要檢查與未修改區的銜接：函數內插值平滑，不代表提前回傳原座標的分支或影響權重邊界也平滑。
4. 對高度等單調量，保形的單調三次插值可減少過衝，但不保證曲率連續。對任意空間路徑，檢查三個座標組成的實際曲線，不能只證明各座標數值單調。
5. 髮束的中心線、寬度、厚度及截面旋轉都要連續。接近直線或反曲點時，避免直接用不穩定的局部法向導致截面翻轉；可使用穩定的框架傳遞並核對截面方向。
6. 把髮尖的收束安排在一段長度內。生成網格時選擇合理的端部拓撲，避免把整圈頂點壓成重合點而留下零面積面；形狀鍵既有頂點順序需保留時尤其要檢查。

不要固定使用某個控制點數或截面邊數；依形狀複雜度、近景尺度和預期多邊形預算決定。

## 既有臉部或有機網格

**先處理基礎形體。** 對頰部到下顎等長過渡，同時看整段輪廓及鄰近曲面，調整頂點走向、過密／過疏邊線和造成夾痕的局部配置。必要時重新分布控制點；單純補密度通常保留原本不好的走向。

**區分固定點與軟限制。** 眼角、口角等需保持的點可固定；眼口邊界周圍使用漸弱影響區。原本有折角的頰顎過渡應允許在造型容差內移動，不能一邊要求修輪廓、一邊固定每個輪廓點。

**小步修整並比較體積。** 局部 Smooth／Relax 可改善細碎凹凸，但可能縮小體積、抹掉下顎或鼓平鼻唇。先改正大輪廓，再有限度清理；容差以模型尺度和保留特徵制定，不照搬公尺數或比例。

**把修改器當成有條件的工具。**

| 工具 | 適合處理 | 仍需核對 |
|---|---|---|
| Smooth Shading、法線工具 | 表面明暗插值或法線不連續 | 外輪廓不會因此自動修正；原法線可能有刻意卡通化設計 |
| Subdivision Surface | 從控制網格生成較細的曲面 | 輪廓收縮、支撐邊／摺痕造成的夾痕、邊界形狀及修改器順序 |
| 局部 Smooth／Laplacian Smooth | 小範圍波紋和不均勻分布 | 體積流失、特徵鈍化；體積選項不保證保住所有局部比例 |
| Corrective Smooth | 變形產生的不良平滑結果 | 原始／綁定狀態、堆疊位置與實際變形；它不是靜態造型的通用美化器 |

對法線的實驗在副本中進行，確認改善後才選擇如何寫回。保留必要的銳邊，不一律清空所有自訂法線或套用所有修改器。

## 帶 UV、權重與形狀鍵的模型

頂點數相同只是維持對應的條件之一；也要保留順序、連接、UV 對應及鍵的相對基準。形體改變後，即使 UV 數值沒變，表面上的貼圖仍可能拉伸。

僅改 Basis 可能使表情相對位移改變；對所有鍵套非線性形變也可能壓壞閉眼與嘴形。按實際控制方式選擇：保留表情位移、把基準修正同步到各鍵，或對各鍵協調變形後另修表情。每種方法都用代表性動作及中間狀態驗證。相鄰的眼皮、眼球、眉睫、嘴內及髮飾若受影響，也需要一起核對。

修復超出現有拓撲能力時，在候選版重建必要區域，安排 UV／權重／形狀鍵的轉移或重做；不要將「保留拓撲」變成無法完成造型的永久限制。
