# 3D 頭髮質感、髮束與流暢度

依指定風格建立細膩表面、清楚髮束層次與連續髮流。髮型由角色設計決定；長短、直捲、分線、髮量、髮色及光澤都不是本技能的固定答案。

## 保留設計，明確描述品質

沿用目前核准的參考與用途。缺少新參考時，保留既有髮型，只改善已辨認的缺陷；容許必要的局部過渡調整，不把每個原頂點都鎖死。單純改色或表面修整不擴大成重新設計髮型。

| 維度 | 目標與判準 |
|---|---|
| 質感 | 明暗能交代曲面與髮流；需要的纖維細節在預期距離可讀，亮區不意外洗白、暗區不糊成一片。依風格決定霧面、亮面或圖案化程度。 |
| 髮束 | 大束統整形狀，所需中小束提供分流、聚合與重疊；粗細、厚薄及間距有主次，能辨認各束也能讀成整體。 |
| 線條 | 路徑、輪廓及截面變化連續，沒有非設計性的折點、夾痕、鼓包或高光跳斷；保留刻意的捲曲、束端、硬邊和亮帶分界。 |

平順不等於全部抹平。低細節、稜角、平塗或強圖案化髮型可符合設計；不強迫每種頭髮有細絲、尖尾、三層分束或連成一條的高光。

## 查實際來源，再決定改哪一層

分析時先用已有證據診斷，不預設修改場景。新建時依設計建立候選；精修既有模型時保留原檔並另存副本。能操作模型時，重開並核對渲染中真正生效的物件、生成來源、修改器／形狀鍵、材質槽、UV／圖集、法線及有效材質輸出。名稱含 card 或 strand 不代表實際構造；曲線可能是生成器輸入，不能只看自身隱藏狀態。節點存在或參數很高，也不證明該效果出現在所用引擎的畫面中。

固定投影、角色尺度、姿勢、燈光及色彩管理，看整體與目標距離，再放大定位。依疑點選對照：

| 觀察 | 優先核對 |
|---|---|
| 剪影有意外折角或鼓包 | 控制點、切線、點距、捲曲路徑、截面與局部取樣 |
| 剪影順，中性材質仍有斷裂 | 曲面起伏、法線、銳邊、交疊與修改器；灰模不能單獨判定是拓撲 |
| 中性表面順，原材質才破碎 | UV 方向、圖案、Bump／Normal、透明排序和受光設定 |
| 關閉細紋後外觀幾乎不變 | 先確認輸出鏈，再衡量該距離下的微細節收益；不要繼續用細紋補救主髮束問題 |
| 靜止成立，動作才夾折 | 權重、形狀鍵、曲線控制或模擬；按實際修改範圍測試 |

需要建模或材質處理時，按相關段落讀 [髮束與表面方法](references/modeling-and-shading.md)。選擇影響已確認缺陷的最小合理改動；主髮束成立時可直接處理材質，不為湊流程重做幾何。

## 修改與驗收

髮束問題先整理路徑、厚薄與分流／遮擋，再增加必要細節。取樣、細分、Smooth Shading、貼圖解析度及節點數都不是品質分數。保留有效的來源設計；局部調整不足、確需換拓撲時，把 UV／權重／控制資料轉移和重驗納入工作。

按 [驗收方法](references/verification.md) 從保存後重開的候選輸出對照。以整體、預期展示距離與相關斜側確認品質，近景用於定位；有必要才加換光、動畫或匯出測試。圖案亮線、髮束邊緣受光與真實細絲分開說明。

回報「看見的缺陷、確認原因、修改、保留設計、實際結果與限制」，交付模型和實圖。分析任務只交診斷；建立或精修任務完成模型與驗收。需要原模型而未取得時，明確標出未執行項，不把建議或概念圖當成完成品。
