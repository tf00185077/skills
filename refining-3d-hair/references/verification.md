# 以實際畫面驗證髮部品質

## 對照應回答一個問題

先固定相機／投影、角色相關尺度、姿勢、燈光、曝光與色彩管理。全角色可用頭部尺寸或瞳距正規化；孤立髮束選相應尺度。保留原展示設定，診斷光或相機另行標示。

按疑點選擇，不要求每次重做全部測試：

| 問題 | 適合的對照 | 能支持的結論與限制 |
|---|---|---|
| 線條有折點 | 剪影、斜側、中性表面，必要時局部換光 | 判斷是否包含輪廓／內部著色缺陷；灰模保留原法線時，不能單獨歸因於拓撲。 |
| 材質細節是否有效 | 保留形體與展示設定，只關閉指定圖案或微法線 | 只證明該距離與條件下的貢獻；多項一起關閉只能判讀聯合效果。 |
| 頭髮像一整塊 | 原材質與中性表面，整體及正常距離 | 查看分束與曲面是否已可讀；透明髮片換不透明材質會改變遮擋／輪廓，必須揭露。 |
| 高光來源不清 | 追蹤輸出及座標，再用換光／相機對照 | 辨認固定圖案與受光反應；不要求圖案化亮帶一律符合物理反射。 |
| 改形後貼圖或動作出問題 | 原貼圖對位、代表性姿勢與中間狀態 | UV／鍵數量未變不能代替實際外觀和功能；沒有控制的靜態模型不宣稱動態通過。 |

例如關閉細色紋與 Bump 後，肖像外觀幾乎不變：先查連線是否有效；若確實有效，則它們不是該條件下的主要可見來源，應轉查束邊、縫隙、形體及其他受光。不要繼續只用節點數解釋髮絲感，也不要外推成微紋永遠無用。

## 接受標準

- **設計保持：** 長短、直捲、髮量分配及主要輪廓符合本次指定；刻意的硬邊、鈍尾、平塗或固定亮帶保留。局部品質提升不擅自換髮型。
- **質感：** 在預期展示距離，所需明暗與纖維層次可讀；沒有非預期的反光洗白、暗部糊合、雜訊或塑膠塊感。近看細節不能代替整體成立。
- **髮束：** 可以追蹤主要髮流與所需分流／聚合，辨認粗細厚薄和前後關係；沒有不預期的穿插、頭皮露縫、等距碎線或融合成塊。
- **連續性：** 問題區域的路徑、輪廓、截面和受光過渡沒有非設計性突變；捲曲與尖銳特徵按設計驗收，不用一個通用角度或曲率閾值取代判讀。
- **功能：** 改到有控制／權重的區域時測必要姿勢與中間狀態；高頻細節用於動畫時檢查時間穩定性；匯出任務在目標格式／引擎檢查材質與透明表現。靜態局部改色不自動升級成完整物理或全身動畫驗證。

數量與數值只作定位資料。連通區、物件、髮束與單根髮絲不是同一計量單位；不同表示法的總面數不能直接成為美觀或等效果效能比。必要時量測局部寬度、特徵點、UV 密度或取樣間距，仍需看實圖。

## 保存與交付

從保存後重新開啟的候選產生最終圖，確認圖片、生成依賴、可見性、有效形狀鍵及修改器狀態。診斷中關閉的效果和臨時光照應還原至交付設定；最終圖須對應實際保存檔。分析腳本以唯讀副本／記憶體運作，避免覆蓋來源。

交付「缺陷 → 確認證據 → 修改 → 保留項目 → 實際結果／剩餘差異」，附模型與同條件對照。分別記錄建模品質、外觀偏好和功能測試；節點存在、雜湊相同或測試無錯誤，都不能代替使用者對質感的認可。

缺少模型、參考或渲染能力時，完成可行的診斷並標出限制。實際未重開、未渲染、未測動態的項目，不寫成通過。
